## Publish on GitHub Pages

1. Create a new public repository named `soni-singh.github.io` (or any name, e.g. `academic-website`).
2. Upload `index.html`, `style.css`, `script.js`, `Soni_Singh_CV.pdf` and `README.md` to the repository root.
3. Go to **Settings → Pages**, set **Source** to "Deploy from a branch", branch `main`, folder `/ (root)`, then Save.
4. After about a minute the site is live at `https://<your-username>.github.io/` (or `https://<your-username>.github.io/<repo-name>/`).
